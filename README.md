# Diffusion and Flow Matching

MIT IAP 2026《Generative AI with Stochastic Differential Equations》课程资料。

## 目录

- `lecs/`：课程幻灯片 PDF。
  - `lecs/translations/`：讲义 1–5 的中文翻译，以及合并文件 `lectures-1-5.zh.md`。
  - `lecs/source_text/`：讲义 1–5 的英文文本抽取，便于对照 PDF。
- `notes/`：课程讲义 PDF。
  - `notes/translations/`：第 1–7 节及附录的中文翻译，以及合并文件 `notes.zh.md`。
  - `notes/source_tex/`：课程讲义对应的 LaTeX 原文片段。
- `labs/`：课程实验 notebook。
